🩺 Amr-Doctor: Multilingual Medical RAG Assistant

Node.js FastAPI Cerebras LLM ChromaDB Medical Guardrails

Amr-Doctor is an advanced medical consultation assistant designed specifically for the Bangladeshi community. It solves the unique local challenge of "Banglish" (Bengali transliterated into Roman script) by utilizing an agentic RAG (Retrieval-Augmented Generation) pipeline to provide accurate, safe, and context-aware medical guidance.

🚀 Core Innovations

  • Banglish-to-Bangla Normalization: A specialized preprocessing layer using Cerebras (Llama 3.1) that transliterates Romanized Bengali into proper Unicode and Clinical English for superior vector matching.
  • Agentic Retrieval: Moves beyond passive search to "Active Reasoning"—decomposing user queries into medical entities (Symptoms, Diseases) before hitting the database.
  • Hybrid Multilingual Search: Simultaneously queries multiple local vector collections (Med QA, Generics) using both Bangla and English embeddings.
  • Medical Safety Interceptor: Real-time emergency detection that triggers immediate hospital alerts for life-threatening symptoms (Chest pain, stroke, etc.).

🛠️ Tech Stack

  • Inference: Cerebras Cloud SDK (Llama 3.1-70B & 8B) for ultra-fast medical reasoning.
  • Vector Database: ChromaDB with shihab17/bangla-sentence-transformer embeddings.
  • Backend: FastAPI (Python) for the RAG Engine + Node.js (Telegraf) for the Telegram Bot interface.
  • Data: Curated medical datasets including clinical generics and verified health Q&A.

🛡️ Safety & Guardrails

The system is built with Clinical Integrity at its core:

  • Confidence Thresholding: Rejects low-confidence retrieval matches (Distance > 1.5) to prevent hallucinations.
  • Strict Context Adherence: The LLM is restricted from using training knowledge for treatments; it only utilizes verified medical context.
  • Automatic Disclaimers: Mandatory professional medical warnings in every response.

📖 Setup & Installation

1. Start the RAG API:

cd api && python app/main.py

2. Start the Telegram Server:

cd server && npm run dev
